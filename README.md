## 中文

Mai C1 Edit Thick Version + Thong 将我们自己的粗腿版本与重新剪裁的 Thong 组合在一起。保留 Mai C1 Edit 的胸前布料、前片和 Obi 调整，提供 10%、15%、20% 三档腿部加粗；Thong 前片收细，腰部衔接更平滑。

每档均提供 Pubic Hair（有毛）和 No Pubic Hair（无毛），共六个独立安装包。同一腿围档位的两种毛发版本，服装、身体与 Thong 模型一致，仅附加毛发不同。

### 安装方法

1. 关闭游戏，选择一个版本并下载 ZIP。
2. 打开 Fluffy Mod Manager，选择 Street Fighter 6。
3. 添加 ZIP，启用对应 MOD。
4. 启动游戏，选择 Mai C1。

切换腿围、毛发或 Thong 组合前，先停用当前 Mai C1 MOD。

### 主要特点

- 组合粗腿造型与重新剪裁的 Thong。
- 提供 10%、15%、20% 三档腿部加粗。
- 袜子与绑腿随腿部轮廓同步调整。
- 每档均有有毛、无毛版本，共六个独立安装包。
- 保留 Mai C1 Edit 的胸前布料、前片和 Obi 调整。
- 保留原有贴图、501 根骨骼与顶点权重。

### 使用要求

- PC 版 Street Fighter 6。
- 游戏中可使用 Mai。
- Fluffy Mod Manager。

## English

Mai C1 Edit Thick Version + Thong combines our thicker-leg options with the reshaped thong. It retains the top-panel, tare and Obi edits from Mai C1 Edit, adds 10%, 15% and 20% leg options, and uses the thong with a slimmer front and smoother waist transitions.

Each thickness has Pubic Hair and No Pubic Hair variants, for six standalone packages. Within the same thickness, the clothing, body and thong meshes are identical between hair variants; only the added hair differs.

### Installation

1. Close the game and download one ZIP.
2. Open Fluffy Mod Manager and select Street Fighter 6.
3. Add the ZIP and enable the mod.
4. Launch the game and select Mai C1.

Disable the current Mai C1 mod before switching thickness, hair or thong options.

### Main features

- Combines thicker legs with the reshaped thong.
- 10%, 15% and 20% leg-thickness options.
- Socks and leg wraps adjusted with the leg shape.
- Pubic Hair and No Pubic Hair options at each thickness, for six standalone packages.
- Retains the top-panel, tare and Obi edits from Mai C1 Edit.
- Original textures, 501-bone rig and vertex weights retained.

### Requirements

- Street Fighter 6 on PC.
- Access to Mai in-game.
- Fluffy Mod Manager.
